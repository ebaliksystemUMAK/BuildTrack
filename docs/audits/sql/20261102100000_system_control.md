# System Control switches and reports

| Field | Value |
|---|---|
| File | `supabase/migrations/20261102100000_system_control.sql` |
| Applied | 2026-11-02 via the connector, live version `20261102024451`, verified (privileges, defaults, profile fingerprint, Cron job; advisor: only intended items) |
| Dependencies | `site_controls`, `feature_locks`, `email_log`, `notifications`, `audit_log`, the 20261101210000 / 220000 function bodies (identical to live before replacing) |
| Reversible | Yes, block at the end of the file. Nothing is deleted by the migration |

| Object | Effect |
|---|---|
| `system_switches` | Two rows (`registration_closed`, `email_paused`), off by default; no API grants |
| `get_registration_status()` | The only function a visitor may call: closed or not, and the message |
| `get_system_switches`, `set_system_switch`, `site_emergency_off` | Super Admin + authenticator; audited (`system.switch`, `system.emergency_off`) |
| `get_email_delivery`, `get_storage_capacity`, `get_system_activity` | Read-only reports, Super Admin + authenticator |
| `complete_registration`, `prepare_access_request`, `redeem_invite` | One added check: refuse while registration is closed (redeem returns reason `registration_closed`) |
| `claim_email_batch` | One added check: returns nothing while email is paused |

## Verification queries (read-only)
```sql
select key, enabled from public.system_switches;                      -- expected: both false
select public.get_registration_status();                              -- expected: {"closed": false, "message": ""}
select p.proname, has_function_privilege('anon', p.oid, 'execute') anon, has_function_privilege('authenticated', p.oid, 'execute') auth
  from pg_proc p join pg_namespace n on n.oid = p.pronamespace where n.nspname = 'public'
   and p.proname in ('get_system_switches','set_system_switch','site_emergency_off','get_email_delivery','get_storage_capacity','get_system_activity','system_switch_on','get_registration_status');
-- expected: anon true only for get_registration_status; system_switch_on false for both
```

## If System Control is unreachable and a switch must be undone (owner, SQL editor)
```sql
update public.system_switches set enabled = false;            -- registration open, email resumed
update public.site_controls set maintenance_on = false;       -- maintenance off
update public.feature_locks set locked = false;               -- every feature pause off
```
